# Grit & Flow Labs

**Grit & Flow Labs** is a Southern, Black-owned creative studio building accessible digital experiences that feel good to use.

We blend hustle and heart: grit for the build, flow for the experience.

## 🌐 Live Site

https://gritandflowlabs.com

## ✨ About

This repository contains the source code for the official Grit & Flow Labs website.

The site serves as the digital home for:
- Mobile applications
- Creative technology projects
- Ongoing web partnerships and maintenance work
- Future product releases

The goal of this project is to maintain a clean, performant, and responsive marketing site that reflects the brand’s identity and direction.

---

## 🛠 Tech Stack

- HTML5  
- CSS3 (responsive design)  
- Vanilla JavaScript  
- Netlify (deployment)  
- GitHub (version control)

No frameworks. No unnecessary dependencies.  
Just intentional, lightweight code.

---

## 📱 Features

- Fully responsive layout (mobile-first)
- Clean, accessible UI
- Brand-aligned design system
- Simple deployment pipeline via Netlify
- Scalable structure for future growth

---

## 🚀 Deployment

This site is automatically deployed via Netlify.

Production branch: `main`  
Publish directory: root (`.`)

Any push to the `main` branch triggers a production deploy.
